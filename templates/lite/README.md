# 智子 Lite 启动包

你好 👋

这是一个小小的启动包。它的作用很简单：把电脑上的 Claude Code 变成一个**懂你、会帮你把事情想清楚、还会记住你**的私人智子助手。你不用懂任何技术，正常和它说话就行。

## 装 Claude Code（只需要做一次）

你不用自己去研究怎么装，也不用看复杂教程。最省心的办法：

打开浏览器，进 claude.ai 网页版，把下面这句话原样复制粘贴给它，让它一步一步带你装：

我想在我的电脑上装 Claude Code，我用的是 Mac（或 Windows），我不懂技术，请一步一步带我装，每次只告诉我一步。

网页版的 Claude 会带你把 Claude Code 装好、登录好。每次它只让你做一步，你照着做就行，不懂就接着问它。

## 用起来（装好之后）

① 安装程序已经在你的家目录里建好了 `zhizi` 文件夹（就是你现在看到的这个），不用解压，也不用挪到桌面。

② 打开电脑上的“终端”，输入 `cd ~/zhizi` 然后回车，就进到这个文件夹了。（不会也没关系，就回到刚才那个网页版 Claude，跟它说“教我在终端里进入家目录下的 zhizi 文件夹”，它会一步步教你。）

③ 在终端里输入 `claude` 然后回车。因为这个文件夹里有一个 `CLAUDE.md`，它会自动读到助手规则，直接变成你的“智子”，主动开始认识你。

④ 如果它没有自动开始，就打开 `FIRST_PROMPT.txt`，把里面那句话复制粘贴给它。

之后，像聊天一样正常说话就可以了。

## 安全红线 ⚠️

为了你的安全，**永远不要**把这些发给它：

- 密码、短信验证码、银行卡号、身份证号。

如果它要帮你登录账号、付钱、改电脑设置——**先停下来，不要点确认。**

## 卡住了怎么办

- 直接问 Claude Code 本身：“我卡住了，下一步怎么办？” 它通常能帮你。
- 还是不行，就**截个图**，发给把这套系统配置给你的人（你的协作者）。这套是 TA 帮你装的，有问题随时找，不用客气。

放轻松，慢慢来。祝你用得开心 🌿
